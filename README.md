# STEM – Střední škola Erazim

Webový průvodce výukou matematiky, fyziky a informatiky (STEM) pro žáky online Střední školy Erazim
a materiály k lekcím v PDF: pracovní listy, další příklady, podklady na dohnání, Must know, obrazové karty,
katalogy zdrojů, ukázkové testy, STEM projekty, karty domácích pokusů, učení s AI a plány výstupů.

Web: otevři `index.html` (GitHub Pages). Repozitář neobsahuje žádné údaje o žácích ani jejich hodnocení.
